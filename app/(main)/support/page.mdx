# Row Games Support

Need help with Row Games? Send an email and include as much detail as you can about the issue, feedback, or feature request.

[**Contact support**](mailto:kristoffer.fredrik@icloud.com)

## What to Include

- What you were trying to do
- Which game and opponent you were playing
- What happened instead
- Your device model and OS version, if relevant
